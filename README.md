# C_Sharp_LINQ_CategoryGrouping

## C#_LINQ_CategoryGrouping

### Задание «Контрольная точка №36 — LINQ: проекции, фильтрация, группировка»

Вариант 1. Товары по категориям
1. `List<Product>` (название, цена, категория) минимум из 8 элементов в 3+ категориях.
2. Сгруппируйте по категории через `GroupBy`.
3. Для каждой группы посчитайте количество товаров и среднюю цену.
4. Спроецируйте результат в анонимный тип или запись с полями: категория, количество, средняя цена.
5. Выведите итоговую сводку по всем категориям через `foreach`.
